# Cryptography Laboratory

A collection of 14 practical experiments covering Cryptography and Network Security, implemented using tools such as CrypTool 2, OpenSSL, Java, Wireshark and Kali Linux.

## Tools and Technologies

- **CrypTool 2** – Classical and modern cryptographic algorithms.
- **OpenSSL** – RSA key generation, encryption, hashing and digital signatures.
- **Java** – Cryptographic algorithm implementation and password hashing.
- **Wireshark** – Network traffic capture and security analysis.
- **Kali Linux** – Password auditing and SSH authentication.
- **Git & GitHub** – Version control and practical documentation.

## Learning Objectives

- Understand classical and modern encryption techniques.
- Implement symmetric and asymmetric cryptographic algorithms.
- Generate and verify cryptographic hashes and digital signatures.
- Work with RSA keys and X.509 digital certificates.
- Analyze secure network communication and TLS traffic.
- Understand password security, hashing and salting.
- Explore SSH-based public-key authentication.
- Develop practical experience with industry-standard security tools.
